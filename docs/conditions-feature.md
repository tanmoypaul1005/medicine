# সাধারণ রোগের ওষুধ গাইড (Common Conditions Guide) — পরিকল্পনা

> অবস্থা: **বাস্তবায়িত — 30টি সমস্যা** (ডাক্তারি যাচাই বাকি) · লক্ষ্য: সাধারণ, হালকা সমস্যায় (জ্বর, মাথাব্যথা, এসিডিটি…) কোন ওষুধগুলো সাধারণত ব্যবহৃত হয় তা **তথ্য হিসেবে** দেখানো — চিকিৎসা পরামর্শ হিসেবে নয়।

## 1. কেন সাবধানতা দরকার

- আগের নিয়ম ছিল "symptom → medicine ফিচার থাকবে না", কারণ ভুল বা নিজে নিজে ওষুধ খাওয়ার ঝুঁকি আছে।
- আমাদের ডেটায় **কোন ওষুধ প্রেসক্রিপশন লাগে আর কোনটা লাগে না (OTC) — সেই তথ্য নেই।**
- `generic.csv`-এর একক "indication" কলাম ভরসাযোগ্য নয় (যেমন Aspirin → "Yellow fever")।

তাই এই ফিচার **নিয়ন্ত্রিত ও সীমিত** রাখা হবে।

| নিয়ম | বিস্তারিত |
|---|---|
| শুধু নির্বাচিত রোগ | 30টি সাধারণ, হালকা সমস্যা (জ্বর, মাথাব্যথা, এসিডিটি, ডায়রিয়া, এলার্জি, গলা ব্যথা, কাটা-ছেঁড়া, ব্রণ, উকুন, রক্তস্বল্পতা…)। গুরুতর রোগ (ডায়াবেটিস, প্রেশার, ইনফেকশন…) থাকবে না। |
| শুধু OTC তালিকা | প্রতিটি রোগের জন্য আলাদা অনুমোদিত উপাদানের (ingredient) তালিকা। **Antibiotic, steroid, ঘুমের ওষুধ, নিয়ন্ত্রিত ওষুধ কখনো দেখানো হবে না।** |
| লেবেলের প্রমাণ | কোনো generic তখনই দেখাবে যখন তার লেবেলের indication অংশে ঐ রোগের উল্লেখ আছে। প্রমাণ বাক্যটি হুবহু দেখানো হবে। |
| ধরন ফিল্টার | Injection/infusion কখনো নয়। চামড়ার সমস্যায় শুধু cream/ointment/gel ইত্যাদি। |
| ডোজ নয় | কত খাবেন তা বলা হবে না — ওষুধের পেজ ও ডাক্তারের কাছে পাঠানো হবে। |
| "ডাক্তার দেখান যদি…" | প্রতিটি রোগের পেজের **শুরুতেই** বিপদ-সংকেত। |
| Disclaimer | প্রতিটি পেজে। |

## 3. ডেটা (সব কিছু ডাটাবেস থেকে)

**নতুন collection: `conditions`**

| ফিল্ড | উদাহরণ |
|---|---|
| `slug` | `fever` |
| `nameBn` / `nameEn` | জ্বর / Fever |
| `aliases[]` | জ্বর, jor, fever, pyrexia (সার্চের জন্য) |
| `summaryBn` / `summaryEn` | ছোট বর্ণনা |
| `redFlagsBn[]` / `redFlagsEn[]` | "3 দিনের বেশি জ্বর থাকলে…" |
| `generics[]` | `{ genericId, name, slug, evidence }` — শুধু OTC, লেবেলের প্রমাণ সহ |
| `formPattern` | কোন ধরন দেখাবে (regex), যেমন `cream|ointment|gel` |
| `reviewed` | `false` — ডাক্তার/ফার্মাসিস্ট যাচাই করলে `true` |

**ডেটা কোথায়:** সব তথ্য সরাসরি MongoDB-র `conditions` collection-এ (প্রথমবার স্ক্রিপ্ট দিয়ে তৈরি হয়েছিল, সেই স্ক্রিপ্ট এখন মুছে ফেলা হয়েছে)। Brand ও দাম runtime-এ `medicines` collection থেকে আসে (সবচেয়ে সস্তা আগে)।

## 6. নতুন রোগ যোগ বা পরিবর্তনের নিয়ম

1. MongoDB-র `conditions` collection-এ সরাসরি document যোগ/পরিবর্তন করুন (উপরের ফিল্ড অনুযায়ী)।
2. `generics[]`-এ শুধু OTC ওষুধ, যার লেবেলে ঐ রোগের উল্লেখ আছে — antibiotic, steroid, ঘুমের ওষুধ কখনো নয়।
3. ক্যাশ রিফ্রেশ: `POST /api/revalidate` (header `x-revalidate-secret`, body `{"tags":["conditions"]}`) — না করলে কয়েক ঘণ্টা পরে নিজে থেকে আপডেট হবে।
